# X Reply Cleaner

一个本地运行的 Chrome Manifest V3 扩展，用于在 X / Twitter 网页里隐藏疑似中文约炮广告回复。

## 功能

- 按关键词识别疑似广告回复
- 按 emoji 数量和联系方式暗示加权
- 额外识别“固炮 / 点击主页 / 主页引导”等高频广告模式
- 识别“擦边话术 + 外链 / 箭头引导 / emoji”的文字型广告
- 识别 `sao`、`yuepao`、`luoliao` 等拼音或中英混写规避词
- 支持屏蔽指定账号或信任指定账号
- 支持只在推文详情页处理回复，尽量不影响主推文
- 设置保存在浏览器本地同步存储，不上传内容

## 安装测试

1. 打开 Chrome 的扩展管理页：`chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本仓库文件夹
5. 打开 X 的推文详情页测试

## 调参建议

- 误杀多：把“屏蔽阈值”从 `6` 调到 `8` 或 `10`
- 漏网多：把“屏蔽阈值”调到 `4` 或 `5`
- emoji 广告多：把“emoji 数量阈值”从 `7` 调到 `4`
- 想看被隐藏内容：打开“显示隐藏提示”

## 说明

这个扩展只在页面展示层隐藏内容，不拦截 X 的网络请求。这样更容易维护，也更适合第一版验证规则是否有效。
